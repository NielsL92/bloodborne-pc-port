The runtime now implements the explicit divide, SIMD, x87 pending/unsupported and MXCSR reserved-bit boundaries through the same noexcept process-stop path. Diagnostics preserve source PC, operation reason/width or raised/unmasked flags, profile identity and FP control/status. This is precise diagnostic stopping, not guest exception recovery. Integer divide zero/overflow report distinct kinds. Invalid MXCSR reports requested and invalid bits while retaining the old State value; SIMD faults retain the newly raised sticky flag.

An FP profile must be supplied explicitly. There is no host/PS4 default. Host setup validates its policy bits, MXCSR mask agreement, identity and sorted unique instruction metadata. An absent profile or unknown x87 instruction site stops. Per-instruction metadata identifies memory/register form, FOP and exact data segment. The recorder checks the semantic IP/FOP/FDP update contract and selects ES/CS/SS/DS/FS/GS from State; it does not assume every memory operand uses DS. This profile mechanism describes supported explicit contracts and does not independently identify the PS4 profile. Whole-image permissions/alignment use registered RAM checks. Existing scoped native x87 numerical helpers link with the pinned SoftFloat library; __udivti3 links from the existing LLVM builtins library.
