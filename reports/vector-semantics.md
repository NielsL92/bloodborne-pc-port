## Semantic changes and independent checks

The original Remill checkout, old lifter and old semantic module remain unchanged. `build/extended-semantics-v3-blend-rsqrt/amd64_avx.bc` includes the authored BMI, SHUFFLE, BLEND and RSQRT extensions. Its identity pins all source inputs, compiler and linked bitcode. The builder now accepts an explicit extension list while preserving its BMI-only default.

- VSHUFPS: 32,768 authored AOT cases cover every immediate, both widths, source/destination aliases and guarded memory. The 256-bit implementation selects independently within each 128-bit lane. It avoids the existing SSE template's unsuitable wide-lane indexing.
- VBLENDVPS, VBLENDVPD and VPBLENDVB: 122,880 cases across thirty forms compare full State and memory against a separate byte-selection reference and authored hardware instructions. Tests include destination aliases with either source or the mask, distinct register/memory contents, unaligned reads and upper-vector clearing.
- VRSQRTPS: 399,360 cases cover six forms and thirty-two combinations of rounding, DAZ, FTZ and exception masks, with varied preexisting status flags. Cases include signed zero, subnormals, infinities, both NaN kinds/payloads, negative values and sampled finite bit patterns. Full State, guarded reads, host/guest MXCSR preservation and VEX upper clearing agree. The maximum measured relative error for positive finite normal values is 0.00030996553293783014.
- The existing 34,816 BMI cases also pass with the combined module.

RSQRT is lowered through the LLVM x86 SSE reciprocal-square-root intrinsic, yielding an AOT instruction inside the newly generated object. It does not execute original game bytes or invoke a CPU fallback. The documented estimate bound is 1.5 times 2^-12; the instruction ignores rounding controls, treats subnormal inputs as signed zero and raises no SIMD floating-point exceptions. Tests check these requirements independently of hardware equality. **Bit-exact AMD Jaguar estimates remain unverified**; host agreement and the ISA bound do not establish console identity. Existing floating-point selectors likewise do not establish complete MXCSR/exception correctness. Source: [Intel instruction manual, RSQRTPS pages 4-576–4-577](https://www.intel.com/content/dam/www/public/us/en/documents/manuals/64-ia-32-architectures-software-developer-vol-2b-manual.pdf). VEX selection and clearing definitions are also in [Intel's AVX programming reference](https://www.intel.com/content/dam/develop/external/us/en/documents/319433-024-697869.pdf).

The last constructor at RVA 0x10326c0 first rejected VSHUFPS, then exposed VRSQRTPS at 0x1032744 and VBLENDVPS at 0x103279b. All three now have tested selectors. Constructor 0x28772a0 compiled after the shuffle extension alone. Both instruction sets were already included in the independent Ghidra comparison of the rejected forty-eight entries; their instruction identities have not changed.
